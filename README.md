# My Claude Rule

## Description

`%USERPROFILE%\\.claude\\CLAUDE.md` を管理する。

## Requirement

- Claude Code 2.1.224

## Install

```powershell
git clone git@github.com:<yourname>/MyClaudeRule.git
```

## Usage

ご利用の端末の `%USERPROFILE%\\.claude` に入れます。
